# themselves and their subdomains (microsoft.com covers learn.microsoft.com);
# other entries must equal the whole match. Email addresses are never
# covered by a domain entry.
# Only genuinely PUBLIC values belong here. Every entry is a permanent hole in
# the scan, so prefer the most specific string that covers the case.
#
# DELIBERATELY ABSENT: dev.azure.com, visualstudio.com, sharepoint.com,
# onmicrosoft.com. URLs on those hosts carry the organisation/tenant name in
# the path or subdomain; allowlisting the host would wave the org name through.
# Write "the wiki" / "the register on SharePoint" instead.
# github.com IS listed, and a github.com URL carries the org/repo in its path.
# Point at a private repo by role ("the scripts repo"), not by URL.
